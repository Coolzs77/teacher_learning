# 初中语文教资面试（10分钟试讲专项）备战工作台

> 面向下半年初中语文教师资格证面试（10分钟试讲），专为考生打造的现代化、离线可用、研修级备考工作台。  
> 拒绝教参假大空，紧扣“10分钟切片教学（一课一得）”、“百字速写教案法”、“口语化示范逐字稿”与“结构化板书设计”。

---

## 🌟 核心特色与功能亮点

### 1. 统编版 6 册教材全量收录（146 篇全文收录）
- 完整收录 **统编版初中语文 6 册教材（七上至九下全部 36 个单元、146 篇课文）**。
- **6 大核心文体体系**：现代写景抒情散文、叙事散文/小说、文言文、古诗词、说明文/新闻、议论文。
- **历年常考星级标注**：5星重点高频篇目（如《春》《背影》《陋室铭》《岳阳楼记》《孔乙己》等）、4星常考篇目与 3 星基础篇目。

### 2. 核心教学工作台（左目录 + 右侧多栏工作台）
- **左侧课文目录导航**：
  - 册次（七上~九下）快速切换，单元主题与单元语文要素清晰呈现。
  - 支持按文体筛选、按考频星级筛选、按备课状态筛选（未学/备课中/已掌握）及标题/作者实时搜索。
- **右侧三大核心功能选项卡**：
  - **选项卡 1【10分钟教学设计】**：
    1. **试讲要求**：还原真实题本 3~4 条考查要求。
    2. **教学切片建议**：明确 10 分钟聚焦教学的核心段落，规避超时或面面俱到。
    3. **考场教学简案设计**：五步结构化提纲，便于考前在草稿纸上速记，支持一键复制。
    4. **教学过程示范（逐字稿）**：包含情境导入、提问互动、学生回答预设、朗读指导与结课作业，口语化自然。
    5. **黑板板书设计**：清晰区分主板书（行文脉络）与副板书（重点字词、技法）。
  - **选项卡 2【课文全文与批注】**：
    - 完整收录各篇课文正文段落，重点试讲切片段落高亮标注。
    - 收录课后思考探究与课下重点字词释义。
    - 支持随堂备考笔记记录，自动持久化存储于浏览器本地。
  - **选项卡 3【教材原版 PDF】**：
    - 内置 PDF 阅读器，选择课文后自动定位到教材对应起止页码。
    - 支持缩放、自适应宽度与翻页浏览。

### 3. 备考概览（Dashboard）
- **文体备考进度统计**：统计 6 大文体已掌握篇目与掌握比例，辅助查漏补缺。
- **面试倒计时**：清晰天数显示，支持自定义考期。
- **每日模拟练待办**：支持每日练习打卡与进度跟踪。
- **高频常考篇目直达**：精选考官高频抽考篇目，一键进入备课。

### 4. 全真考场抽题模拟器（Exam Simulator）
- 模拟真实机考抽签流程，随机抽取试题，生成准考证与试题清单。
- 提供 **备考室速写教案倒计时** 与 **考场 10 分钟试讲倒计时**。

### 5. 悬浮试讲辅助工具（Floating Timer）
- 10 分钟试讲计时器，提供 5 大教学环节进度标识（导入 -> 初读 -> 精读切片 -> 朗读升华 -> 总结作业）。
- 提供流程提词导航，辅助脱稿演练，内置轻柔提示音。

### 6. 文体教学法（Methodology）
- 6 大文体实用试讲结构与教学规范。
- 梳理常见扣分问题、实用教学技巧、示范导入与过渡话术、板书参考结构。

## 🚀 本地运行与构建

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173`。

### 3. 构建静态产物
```bash
npm run build
```
打包输出至 `dist/` 目录，所有路径均为相对路径（`base: './'`），可直接通过任何静态服务器运行。

### 4. 本地预览构建产物
```bash
npm run preview
```

1. **初始化并提交本地代码**：
   ```bash
   git init
   git add .
   git commit -m "feat: 初中语文教资面试10分钟试讲备战工作台"
   git branch -M main
   git remote add origin https://github.com/Coolzs77/teacher_learning.git
   git push -u origin main
   ```
2. **启用 GitHub Pages**：
   - 进入 GitHub 仓库页面 -> 点击 **Settings** -> **Pages**。
   - 在 **Build and deployment** > **Source** 下选择 **GitHub Actions**。
   - 仓库内已内置 `.github/workflows/deploy.yml`，推送到 `main` 分支后将自动触发构建并发布。
   - 部署完成后即可通过 `https://coolzs77.github.io/teacher_learning/` 访问。

## 📄 离线使用说明
- 本系统完全基于浏览器前端运行，所有笔记、打卡记录、模拟练状态均保存在 `localStorage` 中。
- 6 册统编教材 PDF 存放于 `public/textbooks/` 目录下，离线模式下阅读器可平滑翻阅。
