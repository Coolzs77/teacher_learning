# 初中语文教师资格证面试智能备考系统 🎓

> **专为初中语文教资面试打造的一站式备考神器！**  
> 全面收录统编版初中语文（七上/七下/八上/八下/九上/九下）**全部 146 篇课文**，直击“10分钟写教案、10分钟试讲、结构化与答辩”痛点。

---

## 🌟 核心功能亮点

### 1. 📚 统编版初中语文教材全库检索 (146篇课文)
- 覆盖**七至九年级共六册教材**，完整收录每一篇现代文、散文、文言文、古诗词、说明文、议论文、名著导读。
- 支持按**册次**、**文体**（抒情散文、写景散文、文言文、小说、古诗词等）、**中考/教资核心考点**快速筛选。
- 每篇课文内嵌精选课文名句摘录与教材背景信息。

### 2. 📝 10分钟速成教案生成器
- 按照教资面试考官打分标准，自动生成结构化、规范化的**完整教学设计**：
  - **教学目标**（核心素养四维维度：语言建构、思维提升、审美鉴赏、文化传承）
  - **教学重难点**（紧扣新课标与文本特质）
  - **教学方法**（朗读法、问题探究法、批注赏析法等）
  - **标准教学过程**（导入 -> 初读感知 -> 精读品析 -> 拓展探究 -> 课堂小结 -> 作业布置）
  - **规范板书设计**（直观美观的结构化板书演示）
- 支持**一键复制**与**打印/导出为 PDF**，方便考前默写背诵。

### 3. 🎯 真题试讲拆解与讲课逐字稿模版
- **三步试讲黄金法则**：
  1. **入情入境导入（1.5分钟）**：情境激趣、温故知新、以诗入文等多种导入范例。
  2. **主问题链精读探究（6.5分钟）**：提炼 2~3 个层层递进的核心主问题，手把手教你如何设计生生互动、小组讨论、朗读指导。
  3. **升华总结与布置分层作业（2分钟）**：情感升华技巧、多维作业设计。
- 附带**试讲考官评分扣分点避坑清单**（虚假互动、超时/讲不完、缺乏板书等）。

### 4. 🧠 答辩 & 结构化面试题库
- **考官高频答辩题**：收录教学设计意图、语文专业素养、课堂突发应变等高频追问，提供名师标准回答思路。
- **结构化真题库**：涵盖职业认知、自我认知、人际沟通、应急应变、组织管理、综合分析六大模块，掌握万能答题框架。

### 5. ⏱️ 10+10分钟实战考场倒计时
- **备课室模拟（20/10分钟倒计时）**：倒计时提醒、草稿纸写作节奏把控。
- **考场试讲模拟（10分钟倒计时）**：
  - 0~2分钟：导入与感知提醒
  - 2~8分钟：精读主环节提醒
  - 8~9分钟：小结作业提醒
  - 9~10分钟：答辩就绪提醒

### 6. 📅 阶段备考规划与冲刺指南
- 提供从“基础摸底”到“实战模拟”的科学排期规划，助力一次通关！

## 🚀 快速使用

本系统为纯前端单页离线应用（Vanilla HTML5/CSS3/JavaScript），无需复杂安装配置，开箱即用：

1. **直接打开**：双击 `index.html` 或用任意现代浏览器（Chrome、Edge、Safari、Firefox）打开即可使用。
2. **本地服务启动（可选）**：
   ```bash
   # 使用 Python 启动本地测试服务器
   python -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```

## 💡 备考建议与考试流程速览

1. **抽题备课（20分钟）**：
   - 考场电脑随机抽取 1 篇课文片段及试讲要求（通常有 2~3 个具体要求，如“指导朗读”、“有适当板书”）。
   - 迅速使用系统中的“10分钟教案速成框架”列提纲与设计板书。
2. **结构化问答（5分钟）**：
   - 考官随机抽取 2 道结构化题目，沉着冷静，套用综合分析/应急应变模版分点作答。
3. **无生试讲（10分钟）**：
   - 仪态大方，声音洪亮，紧扣抽题纸要求；注意要有自然且规范的“假想互动”，严格把控时间（推荐8分30秒~9分30秒结束）。
4. **考官答辩（5分钟）**：
   - 认真倾听考官提问，虚心坦诚，结合学情与新课标理念作答。
